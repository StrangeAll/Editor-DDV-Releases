# DDV Wizard Editor 0.9.8

## Appearance

- Added a toolbar button to switch between the normal Light mode and Dark mode.
- The selected appearance is remembered after the editor is restarted.

## Furniture

- Added dedicated Furniture tabs for Specials and Presets.
- Added separate and combined Add All actions for Specials and Presets.
- Furniture bulk actions now use the Furniture Dict and block invalid delete-marked fence variants.

## Reliability

- Copying an ID, name, or value now copies only the selected cell.
- Deleting selected items works again across the categories after Furniture.
- Existing unknown or blocked save entries remain visible for review and removal without becoming addable.

## Events and duties

- Added a supported Cheshire Cat Chaos action for its memory, achievements, and missing rewards.
- Added completion of supported permanent Dreamlight, Mist, and Story Magic duties already present in the save.
- Daily duty slots, rerolls, and daily progress remain unchanged.

## Sign-in and support

- Temporary Support Codes can be entered directly in the first sign-in window when email delivery fails.
- Activation and save-profile errors now show a copyable Support ID and the exact editor build.
- Applied Dict versions are reported more accurately for support and distribution checks.

## Updates

- Added signed complete-editor updates alongside protected Dict updates.
- A failed local installation restores the previous editor files.
